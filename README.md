# Tàng Kinh Các Server

Tàng Kinh Các Server là dự án backend cá nhân tôi xây dựng để hỗ trợ quá trình phát triển ứng dụng Tàng Kinh Các. Repo này không phải ứng dụng dành cho người dùng cuối mà là phần máy chủ được phát triển độc lập để ứng dụng Android có thể kết nối và sử dụng.

Server đảm nhiệm việc cung cấp tài khoản người dùng, thông tin sách, tác giả, thể loại, nội dung EPUB và sách nói. Nhờ đó, ứng dụng chính có thể tập trung vào trải nghiệm đọc và nghe, còn dữ liệu cùng các quy tắc truy cập được quản lý tập trung ở phía server.

Đây cũng là nơi tôi phát triển, thử nghiệm và hoàn thiện phần backend trước khi tích hợp với ứng dụng Tàng Kinh Các. Thông tin về kiến trúc, cài đặt và quá trình phát triển được trình bày riêng trong thư mục [`docs`](docs/).
